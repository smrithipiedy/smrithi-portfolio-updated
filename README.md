# Smrithi | Portfolio 🚀

A premium, retro-futuristic portfolio built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**. Featuring smooth animations, dynamic tech stack visualizations, and a unique experience timeline.

![Portfolio Preview](public/placeholder.svg)

## ✨ Features

- **Interactive Hero**: Dynamic typography with a typing cursor effect and retro-futuristic glow.
- **Experience Journey**: A vertical timeline with a "shooting star" active trail that follows your scroll.
- **Animated Tech Stack**: Progress bars that re-animate smoothly every time you switch categories using `framer-motion`.
- **Achievements Section**: A dedicated "Milestones & Wins" section for hackathons and open-source contributions.
- **Live Contact Form**: Fully functional email sending integrated with **FormSubmit.co**.
- **Responsive Design**: Optimized for everything from mobile phones to ultra-wide displays.
- **Modern UI**: Dark mode by default, featuring glassmorphism, floating particles, and custom cursor effects.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) (Vite)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Space Grotesk, JetBrains Mono, VT323

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/smrithipiedy/purple-updated-portfolio.git
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Start the development server:
   ```sh
   npm run dev
   ```
